# v0.5.0 其他电脑安装验收清单

状态：待其他电脑执行。本机 Windows 11 x64 通过不替代本清单。不要提交账号文件、数据库、Cookie、手机号或 Token。

## 环境记录

- [ ] 记录 Windows 版本/位数、安装包版本、SHA256、首次安装或覆盖安装。
- [ ] 确认 Windows 10 及以上 x64，D 盘存在且目标可写；无 D 盘不属于当前支持范围。
- [ ] 保持 Windows 防护启用，记录实际拦截提示；不把拦截猜测成程序错误。
- [ ] 使用原 Windows 用户；DPAPI 密文不能直接跨用户/机器通用。

## 首次安装

- [ ] 验证 SHA256SUMS.txt，再运行 Setup，选择 D 盘程序目录及桌面快捷方式。
- [ ] 安装成功后桌面和开始菜单链接存在，双击能够打开 GUI。
- [ ] 自检无网络也可通过；不能因 GitHub 限流/无 Release/断网回滚。
- [ ] “设置→检查更新”显示真实结果：无正式 Release、最新、限流、权限或网络失败；窗口仍可正常使用。
- [ ] 豆包工作只读入口能打开；客户端未运行时如实提示，不显示虚假额度或已签到。
- [ ] 官方客户端打开额度页后可刷新；身份未验证、签到状态仍未知，记录保存后重启可查看。

## 覆盖安装（不要先卸载）

- [ ] 关闭 AIClockIn；另行备份 data，不把备份上传或打包。
- [ ] 记录原安装和 data 目录、WorkBuddy/Trae 账号数量、自定义名称、启停状态、历史记录及自动任务设置。
- [ ] 沿用原目录覆盖安装；安装后上述项目均保留，无重新登录要求。
- [ ] 桌面链接仍指向正确 EXE，并使用原 data 路径。
- [ ] 豆包记录仍为按次未绑定记录，不与其他账号或签到成功混淆。
- [ ] Windows 计划任务命令是原绝对路径 EXE --silent，当前用户/参数/触发器不变；先查看任务结果，不为测试重复领取。

## 卸载与重装

- [ ] 卸载仅移除程序和自有链接；账号、SQLite 和历史仍保留。
- [ ] 在原 Windows 用户下重装，确认恢复原 data；不手动删除 data。
- [ ] 不将源码仓库作为安装目录，检查无关源码、用户文件未被删除。

## 失败诊断与回滚

- [ ] 安装失败时保存安装目录 diagnostics/install-*/install.log 和 health.json；未生成 health.json 时保留启动/退出码日志。
- [ ] 检查日志是否说明阶段、异常类型、退出码或超时，不接受只有“新版本检查失败”的结论。
- [ ] 覆盖失败后旧版仍可启动，data、历史和任务保留；没有旧版本的首装失败不留下可误用启动文件。
- [ ] 不在真实用户安装上故意破坏依赖或注入失败；故障注入仅在独立 AppId 和合成数据环境进行。
- [ ] 可选命令：`AIClockInSetup.exe /LOG="D:\AIClockIn-setup.log"`。
- [ ] 可选离线检查：`AIClockIn.exe --self-test --report "D:\AIClockIn-diagnostics\health.json"`。

## 发布后在线更新（当前未执行）

- [ ] GitHub 正式 Release 已含版本安装包、SHA256SUMS 和更新说明，无 draft/prerelease。
- [ ] 旧版设置检查可发现新版本、显示远程说明，HTTPS 下载及 SHA256 通过。
- [ ] 辅助程序等待旧进程退出，安装后自动启动，账号/历史/自动任务保留。
- [ ] 网络断开、限流和校验失败均不破坏原版本；不要在真实数据上人为制造安装失败。

验收反馈只需：勾选结果、环境、安装/错误阶段、脱敏诊断和截图。当前尚未通过 Windows10实体机、其他实体电脑、Defender拦截、受控文件夹策略及发布后的真实在线更新验证。
