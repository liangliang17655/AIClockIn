## 设计与影响

- 复用当前单文件 EXE 内的 Python/Tk，增加安装窗口及 `--install`，无需另套运行时。新下载首次 GUI 启动且没有本地数据、没有显式 --data 时显示安装窗口；开发源码、静默任务、授权、自检、更新辅助分支不自动安装。
- 新用户默认 `D:/AIClockIn/AIClockIn.exe`，数据为旁边 data；安装后自动创建当前 Windows 用户桌面的“AIClockIn 自动签到.lnk”。桌面位置由 Windows 获取，允许其在 C 盘：用户明确要求桌面入口，只写这一个快捷方式，不将程序/数据放 C 盘。
- 已有本地数据或当前用户 AIClockIn-Auto 已指向有效安装时，保留其原 EXE/data 路径并禁止安装窗口移动它们。设置增加“安装 / 创建桌面快捷方式”，已有用户可补入口。不会自动切换生产任务或迁移凭据。
- 同一路径、同一 EXE 时只创建快捷方式；覆盖旧程序复用已验证更新事务；新目录安装先 D 盘暂存、校验/离线健康检查，再替换到最终路径。无论安装源在 C 盘桌面还是 D 盘下载目录，都不在源旁创建 data。
- 链接固定目标绝对路径、工作目录及 `--data`。同名链接目标/参数相同可以复用；不同则拒绝覆盖，保留原链接。创建链接失败如实报告可重试，不伪装整体成功。
- 自动更新仍选择版本化正式 Release EXE，在原安装位置更新，快捷方式和计划任务路径不变。README 继续直达 EXE，文案改为下载后双击安装。
