# AIClockIn v0.5.0

## 更新内容

- 新增豆包工作当前会话只读额度查询：活动累计、活动赠送总额/已用/剩余及到期时间。
- 查询记录复用本地 SQLite，未知字段为空，未确认身份时每次独立保存，不按昵称合并账号。
- 锁屏或客户端退出时如实记录查询失败，不沿用缓存、不误报登录失效。
- 更新检查区分 GitHub 匿名限流、访问拒绝、网络异常、无正式 Release 和已是最新版本；限流不立即自动重试。
- 保留 WorkBuddy、Trae CN 核心、账号加密、历史记录及原有 Windows 自动任务。

## 下载与安装

附件应为 `AIClockIn-v0.5.0-Setup-windows-x64.exe` 和 `SHA256SUMS.txt`。验证校验值后运行 Setup，已有用户关闭软件后沿用原目录覆盖安装，无需先卸载，不删除 data。

支持范围：Windows10及以上 x64、D盘可用；本机实测为 Windows11 x64，其他电脑尚待验收。EXE不需要单独安装Python。目录版EXE不可离开随附运行时单独分发。

## 已知限制

- 豆包工作只读依赖官方客户端相关页面；没有自动领取，不进入后台签到任务。
- 豆包账号身份未确认、今日签到证据不足时保持未知；累计或卡片额度不代表今日奖励到账。
- UIA 读取当前显示内容，不替代官方页面刷新；跨版本结构变化会返回未知。
- GitHub 匿名 API 按出口 IP 共享配额，公共代理可能限流；客户端不包含个人 Token。等待重置后重试，不影响现有功能。
- 跨电脑安装兼容性与发布后的公网完整更新链路尚未验证，不宣称全部解决。
- 软件未获得可信代码签名，更新不代表 SmartScreen 提示消失。

本机安装、恢复、任务等具体结果及跨电脑清单见仓库 docs/RELEASE-0.5.0-READINESS.md、docs/INSTALL-ACCEPTANCE-0.5.0.md。模拟测试不等于真实签到验收。
