# v0.5.1 其他电脑验收（尚待实际执行）

适用Windows10/11 x64、D盘存在且安装位置可写。保持Windows防护启用，使用原Windows用户，不移动或删除data。不要发送账号文件、数据库、Token或Cookie。

- 首次安装：核对SHA256，运行Setup选择D盘目录、桌面快捷方式；成功后桌面/开始菜单启动正常，主界面仅有两个正式平台入口。
- 覆盖：关闭软件，备份data后运行Setup沿用原目录，无需先卸载；核对账号、启停状态、历史、更新偏好及原计划任务路径保留。
- 离线安装：断网也能完成本地自检。网络检查失败不能导致安装回滚。
- 更新：设置→检查更新；验证有新版、无新版及断网提示。API限流时官方Release后备源可用才继续，否则如实报错。
- 后台任务：开启自动签到后关闭GUI，确认任务直接调用当前EXE绝对路径和原data参数；真实业务结果以实际账号/接口为准，失败不记成成功。
- 卸载/重装：仅清理本安装程序和自有快捷方式/任务；原账号数据仍在。重装使用相同数据目录，原Windows用户可解密。
- 失败：记录Windows版本、安装包SHA、安装目录与安装/覆盖方式；保留安装目录diagnostics/install-会话/install.log、health.json及安装器日志。先审查脱敏后提供日志，不发送data。

本机通过上述隔离验证不能代替这份跨电脑清单；此前其他电脑错误只有截图而无实际异常日志，不能断言所有原因都已排除。
